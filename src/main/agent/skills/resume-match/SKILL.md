# 简历与岗位匹配

使用 `match_resume` 工具取得用户选定简历中尽可能提取的文字和视觉内容，以及用户提供的 JD 或职迹内岗位说明。若缺少简历或岗位信息，调用 `ask_user` 获取必要信息。文字和页面图像是同一份简历的互补证据；文字为空但提供了页面图像时应继续分析。工具明确报告没有提取到任何可用内容时，不得猜测简历事实。

输出 0–100 的匹配分数，说明评分依据，并分别列出有简历文字证据支持的优势与 JD 要求中尚未找到证据的缺口。将“未找到证据”与“确定不具备”区分开。不要编造工作经历、技能、学历或面试结果；不要未经用户请求修改任何职迹数据。
