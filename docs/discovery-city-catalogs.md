# 岗位发现城市目录维护

目录按平台独立保存在 `src/shared/discovery-cities/`，由 `src/shared/discovery-cities.ts` 注册，运行时不下载。本文于 2026-10-10 更新；以下统计来自仓库中核验日期为 2026-10-09 的六份官方目录快照，不代表重新联网核验。数量是快照说明，不是业务限制或固定测试断言。

Main 的每个平台 adapter 仅加载自己的 JSON，使用 `discovery-city-catalog.ts` 的纯函数构建索引，经 `PlatformAdapter.cities` 提供查询。Main 的 Service、运行时及平台能力均通过 adapter 访问目录；全平台元数据注册表仅供 Renderer 选择城市与诊断使用，adapter 不反向依赖该注册表。两端共享同一份 JSON 和索引算法，回归测试核对所有城市、别名及原生代码一致。

## 数据来源与取值层级

- BOSS：[官方城市接口](https://www.zhipin.com/wapi/zpCommon/data/city.json)。读取 `zpData.cityList` 各省级分组的直接子项，保留 `firstChar` 和官方名称，不展开下属区县。独有选项包括白杨市、东沙群岛。
- 猎聘：[官方地区接口](https://api-dok.liepin.com/api/com.liepin.bd.p.v4.get-all-dq?part=part_1%2Cpart_2%2Ccountry%2Cprovince&sc=0&from=component)。取 `part_1.list` 中父级属于 `province.list` 的 `ca=3` 城市，以及四个直辖市和港澳台；不展开 `part_2` 区县。公开网页网关需要 `X-Client-Type: web`、`X-Fscp-Version: 1.1`、`X-Fscp-Std-Info`（`client_id: 40108`）、`X-Fscp-Bi-Stat`（官网 location）和新的 `X-Fscp-Trace-Id`，缺失时可能返回 `-1400`，不代表必须登录。父级代码保留网站分组（港澳台为 `gangaotai`）。补回选项还包括雄安新区、杨凌。
- 智联：[官方地区关系接口](https://fe-api.zhaopin.com/c/datanormalization/region-relation?maxLevel=3&canSelectCity=1&canSelectProvince=0&canSelectUnlimit=0&canSelectWholeCountry=0&canSelectForeignCountry=0)。取省级分组下 `CITY` 和 `MUNICIPALITY`；热门分组只补入直辖市并按代码去重，港澳台分别使用自己的省级归属，排除国外及 `DISTRICT`。北屯市代码为 `932`，不能误取台湾北屯区。补回选项还包括西咸新区、洋浦经济开发区。
- 前程无忧：[官方城市字典](https://js.51jobcdn.com/in/js/2023/dd/dd_city.json)。取字母分组（`type=0`）和港澳台（`type=3`），不收录全国、省份、国外分组；省级归属按官网代码所属省份核对。完整保留网站直接列出的城市级选项，包括昆山、常熟、义乌、雄安新区等，不继续展开其普通区县。
- 国聘：[官方地区树](https://gp-api.iguopin.com/api/base/districts/v1/tree)。保留城市级节点，以及直辖市和港澳台的整地区选项，共 373 项；不将普通省份和下属区县列为独立选项。`code` 保留官网的点分层级字符串，`parentCode` 保留省级分组代码。例如北京为 `000000.110000`，上海为 `000000.310000`，三沙为 `000000.460000.460300`。适配器按省级分组及原始控件名称选择城市，直辖市使用官网“全北京”等整地区选项。
- 实习僧：[官方城市目录](https://www.shixiseng.com/proxy-prefix/new-intern-api-host/api/interns/v3.0/interns/cityall)。取“全国 → 区域 → 省级分组 → 城市”的 395 个直接城市选项，不展开下属区县，不重复收录热门城市，不收录海外分组。查询值是官方名称，`code` 与 `platformName` 相同，例如北京为 `北京`，上海为 `上海`，不能套用其他平台的数字编码。新竹与新竹县、嘉义与嘉义县分别保留，避免合并不同的官方筛选项。

目录读取与岗位采集分别验收。官方目录或岗位网页可以匿名访问，不改变客户端必须登录才能实时采集的规则；国聘与实习僧采集前还会通过官方账号接口检查现有会话。完整认证规则见 [岗位发现](job-discovery.md#账号与会话)。

## 更新规则

每个 JSON 独立包含 `verifiedAt`、`sources` 和 `cities`。城市保存规范 `name`、`province`、`initial`，以及本站 `code`、`platformName` 和需要时的 `parentCode`。所有代码均为字符串，保留前导零。

**交集只对 `name` 做字符串精确匹配**，不解析城市语义、不比较省份、不在运行时移除后缀或展开别名。省级归属仅用于目录核验及官网控件选择。名称在源 JSON 中逐项规范：同一地点统一行政后缀及民族自治全称，例如“北屯市”→“北屯”，“恩施州 / 恩施土家族苗族自治州”→“恩施”，“锡盟 / 锡林郭勒盟”→“锡林郭勒”。“广州”等地名本身的“州”保留；新竹县、嘉义县等用于区分不同地点的后缀保留，不机械删除。各平台提供的地区粒度不变。

`platformName` 保留官网控件的原始展示名，不参与交集。`aliases` 显式列出已有查询名称和官网别称，只用于历史查询及城市代码查找，不增加选择器选项，也不参与交集。不在运行时生成别名或猜测后缀。

更新时读取完整官方目录，核对新增、删除和代码变化，不从其他网站目录裁剪数据。统一源数据中的名称，确保每个平台规范名称和代码唯一；若出现不同地点同名，维护源数据时为它们设置一致且可区分的名称。特别检查直辖市、省直辖地区、自治州简称、港澳台和网站自有城市级选项。

执行城市目录、真实选择器、发现页面、Service/MCP 和来源适配器测试；使用单站特有城市和多站共同城市核验官方控件及实际提交代码。登录或验证阻塞必须记录，不能以“空结果”或目录存在替代采集成功。

## 城市名称国际化

英文展示名集中维护在 `src/renderer/discovery-city-names.ts`，覆盖六个平台目录并集的 412 个地区。`i18n.ts` 将其注册为 `discoveryCities` 文案；中文展示使用规范名称。新增城市时补充一次英文译名，无需给各平台目录重复添加译名。英文同名项显式附加省份，例如苏州和宿州分别显示 `Suzhou (Jiangsu)`、`Suzhou (Anhui)`。

城市选择器和搜索历史标签随 `zh-CN` / `en-US` 切换；选择器在两种语言下都支持中文和英文搜索，忽略英文字母大小写、重音、空格和音节分隔符。切换语言只更新展示，保留已选值、平台集合和锁定状态。历史别名通过已有目录映射展示译名，未知历史城市保留原文。官网返回的岗位地点、公司名和 JD 不自动翻译。

交集、城市代码查找、搜索提交、MCP 能力列表及持久化查询继续使用规范中文名称和原有代码；英文标签不作为查询标识，也不参与交集。所有译名随应用发布，运行时不联网翻译。

普通地名采用拼音，常用译名及多音字单独核对，不直接把招聘站的拼音字段当作英文名。例如 BOSS 的长治、蚌埠拼音字段需要纠正，新增城市中也存在缩写。特殊地名参考[国务院英文网站的新疆地名用法](https://english.www.gov.cn/archive/whitepaper/202107/14/content_WS60ee599bc6d0df57f98dcd8c.html)及[国新办英文网站的西藏地名用法](https://english.scio.gov.cn/2019-03/27/content_74618430_11.htm)，在源码中保存最终显示文本，不在运行时推导。

国际化专项历史验收（2026-10-09，原四平台目录）：城市目录、真实选择器和发现页面共 57 项测试通过，类型检查、构建、格式检查通过。Windows 打包界面已验证从设置切换语言后返回岗位发现，城市标签更新且选择保留，并验证中文界面输入英文、英文界面输入中文搜索城市。新增平台的目录与译名覆盖由六平台目录测试检查。
