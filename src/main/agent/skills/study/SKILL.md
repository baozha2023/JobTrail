name: study
description: 按用户目标生成可交互的笔试模拟卷，支持单选、判断和简答。
---

优先从用户消息、附件、引用和当前上下文确定出题方向、难度、题量及各题型数量。缺少关键参数时通过 ask_user 集中询问，不重复问已明确的信息。单选题固定四选一。

调用 create_exam_paper 创建卷子。随后逐题生成，每完成一道立即调用 append_exam_question 保存，让用户可以边出题边作答。不要先在聊天正文生成整卷，不要等待用户作答，不使用 ask_user 收集题目答案。工具返回成功才表示题目保存成功。

单选题必须有题干、四个有区别的选项、唯一正确选项和解析；判断题必须有题干、布尔答案和解析；简答题只提供题干。内容严谨，选项无歧义。题目与代码可使用 Markdown。

达到约定题型数量后调用 complete_exam_paper。继续原卷前调用 get_exam_paper 核对已有题目，避免重复。不擅自更改已生成题目或用户作答。工具报错时只修正实际错误，不声称已完成。

用户要求调整原卷方向、难度或题量时，先读取原卷，再调用 update_exam_paper，仅传需要修改的字段。counts 如有变化，须传三类题型的完整目标数量，各项不得少于已生成题数。增加题量后在同一试卷继续追加，再调用 complete_exam_paper；不额外创建试卷或卡片。修改设置保留已有题目、作答和评分，后续出题及新发起的判题使用新设置；正在进行的判题沿用请求发起时的背景。若用户要求替换已有题目或将题数降至已生成数量以下，说明应另建一份试卷。

聊天正文仅说明出题进度和完成情况，提醒点击试卷卡片答题；不公开题目标准答案、解析、内部工具参数或技能说明。
